# 🀄 モシラス — 雀荘アテンドシミュレーション

フリー雀荘の店長になって、開店〜閉店まで卓を回し、**売上（場代）を最大化**するブラウザシミュレーションゲーム。Astro + Tailwind v4 の静的サイトで、GitHub Pages にデプロイされます。

プレイURL: `https://satory074.github.io/moshirasu/`

## ゲームの仕組み

実在のフリー雀荘の運営をモデル化しています。

- **客は希望卓を持って来店**：ブルー卓(点5) / グリーン卓(点3) / どちらでも良い。
- **卓は4席**。4人揃えば1卓成立。3人以下でも **本走**（店員が人数合わせで着席）で対局可能。ただし本走席は**場代を生まない**＝あくまで人数合わせ。
- **場代**＝プレイヤーの売上。客1人 × 半荘ごとに徴収。点5の方が場代も高い（振り分け判断が生まれる）。
- **ラスハン / モシラス**：各半荘の開始前に着席客がコール。**ラスハン**＝必ず次で最後（席が確実に空く）、**モシラス**＝最後かもしれないし続けるかも（確率で解決）。待ち客を待たせるか即案内するかの読み合い。
- **交代**：東場の間だけ、本走席に待ち客を入れられる（客が点棒・親状況に納得すれば）。
- **合卓**：半荘前の同レート2卓を1卓にまとめ、本走店員を解放。
- **客が帰る条件**：待たせ過ぎ（怒り）／帰宅時刻到達／負けが込んで資金が尽きる（飛び）。

### 勝敗・資金シミュレーション

各半荘ごとに、客の **強さ・ツキ** ＋乱数で着順1〜4を決定 → 点棒スプレッド生成 → オカ(25000持ち30000返し)・ウマ・祝儀（点5のみ・ゼロサム）を適用 → レートで円換算 → 資金に反映。点5は振れ幅が大きく、たまに大物手直撃で薄い資金の客が飛びます。

## 開発

```bash
npm install
npm run dev        # http://localhost:4321/moshirasu/
npm run build      # 本番ビルド（dist/）
npm run typecheck  # astro check
npm run test       # エンジン＋DOMのスモークテスト（tsx + jsdom）
```

同一シードで遊ぶには URL に `?seed=12345` を付与。

## アーキテクチャ

`src/game/` はフレームワーク非依存の純TSエンジン。`render.ts` / `main.ts` のみ DOM を触ります。

| ファイル | 役割 |
|---|---|
| `types.ts` | 全エンティティ型 |
| `config.ts` | **全バランス定数**（調整はここだけ） |
| `rng.ts` | seed付きPRNG（`?seed=` で再現可能） |
| `state.ts` | 状態ファクトリ＆ヘルパー |
| `economy.ts` | 着順精算・場代・資金（純数式） |
| `customers.ts` | 来店・待ち・去就 |
| `tables.ts` | 卓・席・半荘進行・本走・交代・合卓 |
| `actions.ts` | プレイヤー命令層 |
| `engine.ts` | リアルタイム tick ループ（rAF + 固定タイムステップ） |
| `selectors.ts` | 描画用の派生ビュー |
| `render.ts` | state → DOM（keyed更新 + イベント委譲） |
| `main.ts` | 合成ルート |

## デプロイ

`main` ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）が `dist/` を Pages に公開します。
